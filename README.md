# FRONTIER 2 — Three-Race Solo RTS

스타크래프트: 브루드 워의 세 종족을 참고한 **브라우저용 솔로 RTS 샌드박스**입니다. 테란·저그·프로토스로 채집, 기지 건설, 연구, 유닛 생산, 공격과 스킬을 시험할 수 있습니다. 멀티플레이와 외부 서버 통신은 없습니다. 웹 호스팅 배포도 설정하지 않았습니다.

원작 게임 엔진이나 추출 리소스를 사용하지 않습니다. 지형·건물·유닛은 Canvas로 직접 그리며, 밸런스와 규칙 일부는 이 샌드박스에 맞게 단순화했습니다. 원작 엔진의 완전한 재현을 의미하지 않습니다.

## 바로 실행

Node.js가 설치된 환경에서:

```sh
npm start
```

브라우저에서 **http://127.0.0.1:4173/** 을 여세요. 추가 패키지 설치나 빌드는 필요 없습니다. 이미 실행 중이라면 새로고침하면 됩니다.

1. 왼쪽 위 종족 버튼에서 **테란 / 저그 / 프로토스**를 선택합니다.
2. 일꾼 선택 후 미네랄을 우클릭해 자원을 채집합니다. 일꾼의 **건설** 메뉴로 기지를 확장합니다.
3. 시설을 선택해 유닛을 생산하고 **연구** 탭에서 기술을 개발합니다. 명령이 많으면 화살표나 `Tab`으로 다음 페이지를 엽니다.
4. **F2 전투 실험실**에서 적을 배치합니다. 적 우클릭은 집중 공격, `A` 후 지면 클릭은 공격 이동입니다.
5. 유닛의 **스킬** 탭에서 능력을 고르고 대상을 클릭합니다. 기술·에너지·사거리·재사용 시간이 적용됩니다.

바로 스킬을 시험하려면 F2에서 **모든 기술·선행 조건 해제**를 켜고, **아군 (시험용)**으로 원하는 시전자를 배치하세요. 시험용 시전자는 에너지가 채워져 있습니다. 자원 추가, 비용 없음, 아군 무적, 선택적 안개 표시도 제공합니다.

## 능력

- **테란:** 수리, 치료, 스팀팩, 시즈 모드, 스파이더 마인, 은폐, 락다운, 핵 공격, 디펜시브 매트릭스, EMP, 이레디에이트, 야마토 건, 리스토레이션, 옵티컬 플레어, 스캐너 탐색, 핵탄두 생산.
- **저그:** 잠복, 다크 스웜, 플레이그, 컨슘, 패러사이트, 인스네어, 브루들링 생성, 커맨드 센터 감염.
- **프로토스:** 사이오닉 스톰, 할루시네이션, 아칸·다크 아칸 합체, 피드백, 마엘스트롬, 마인드 컨트롤, 디스럽션 웹, 스테이시스 필드, 리콜, 실드 충전, 스캐럽·인터셉터 생산.
- **수송:** 탑승, 모두 하차.

스킬은 표시만 하는 버튼이 아니라 실제 피해·회복·상태·소유권·이동 효과를 적용합니다. 스톰·EMP·일부 범위 상태 효과는 아군에게도 영향을 줄 수 있습니다. 각 버튼 툴팁과 F3 도감을 참고하세요.

## 조작과 저장

| 입력 | 기능 |
| --- | --- |
| 좌클릭 / 드래그 | 단일 / 다중 선택 |
| Shift + 좌클릭 | 선택 추가·제거 |
| 적 우클릭 / 자원 우클릭 | 집중 공격 / 채집 |
| `A` 후 지면 클릭 | 공격 이동 |
| Shift + 우클릭 | 명령 예약 |
| 더블클릭 | 화면 안 같은 종류 유닛 선택 |
| Ctrl + 1–9 / 1–9 | 부대 지정 / 선택 |
| 방향키 / 화면 가장자리 | 카메라 이동 |
| 휠 / Space | 확대·축소 / 기지로 이동 |
| `B` / `V` | 건설 / 추가 스킬 메뉴 (유닛별 버튼 참조) |
| `Tab` | 명령 다음 페이지 |
| `P` / Esc | 일시 정지 / 명령 취소 |
| F2 / F3 | 전투 실험실 / 도감 |

버튼 우측 위 단축키는 현재 명령 페이지에 맞춰 바뀝니다. 일시 정지, 0.5×/1×/2× 속도, 선택적 효과음, 전체 화면 및 좁은 화면 HUD를 지원합니다.

진행은 **종족별로 분리하여 15초마다 localStorage에 저장**합니다. 게임 메뉴에서 수동 저장·불러오기도 가능합니다. 종족 전환은 현재 기지를 저장한 뒤 다른 종족의 저장을 불러옵니다. 새 게임은 확인 후 해당 종족의 저장을 교체합니다. 기존 v1 테란 저장은 v2로 이전하되, 원본 `frontier-save-v1` 키는 삭제하지 않습니다.

## 검증

```sh
npm run check
npm test
```

59개 시뮬레이션 검사는 실제 `data.js`와 `engine.js`를 별도 VM에서 실행합니다. 세 종족 경제·건설·라바·변태·동력·애드온, 모든 생산 유닛, 공격·공중 표적·탐지, 주요 스킬 효과, 수송·탄약·연구, 저장 복원 및 v1 이전을 검증합니다. 실제 UI는 브라우저에서 종족 전환, 생산/스킬 메뉴, 도감 검색, 스톰 시전·에너지 소모, 390px 화면의 HUD를 별도로 확인했습니다.

## 구현 범위와 차이

이 버전은 **세 종족 전체 일반 유닛 목록과 핵심 전투·기술을 다루는 자체 엔진**입니다. 원작의 프레임 단위 판정·정확한 밸런스·애니메이션·사운드를 그대로 재현하지 않습니다. 비용은 친숙한 형태를 따르지만 생산/연구 시간·거리·일부 효과를 실험에 맞게 조정했습니다.

- 평지 맵만 사용합니다. 고저차, 지형 편집, 캠페인·영웅·에디터 전용 유닛은 없습니다.
- 크립/파일런 범위와 시야는 거리로 근사합니다. 선택적 안개는 현재 시야를 덮는 표시이며 탐험 지도를 누적하지 않습니다.
- 캐리어 요격기와 리버 스캐럽은 보유 수·탄약·공격 효과로 처리하며 개별 경로를 가진 하위 유닛으로 시뮬레이션하지 않습니다.
- 저그 변태·프로토스 합체와 핵 공격은 지연/완료 효과를 구현하며 원작의 모든 중간 애니메이션·취소 규칙을 동일하게 구현하지 않습니다.
- 적은 전투 연습용 표적 또는 진격 부대입니다. 상대의 채집·기지 건설·전략 AI는 없습니다.
- 멀티플레이, 계정, 원격 저장 및 웹 배포는 추가하지 않았습니다.

## 파일 구조

- `dist/data.js`: 세 종족의 유닛·건물·능력·연구 정의
- `dist/engine.js`: DOM과 분리된 경제·경로·전투·능력·저장 시뮬레이션
- `dist/graphics.js`: 직접 그린 픽셀 스프라이트·지형
- `dist/game.js`: HUD·입력·종족별 저장·전투 실험실·도감
- `dist/index.html`, `style.css`, `expansion.css`: 반응형 UI
- `server.mjs`: 의존성 없는 로컬 정적 서버
- `test-game.mjs`, `scripts/check.mjs`: 회귀·문법 검사

StarCraft는 Blizzard Entertainment의 상표입니다. FRONTIER는 공식 제품과 관계없는 개인 실험용 팬 프로젝트입니다.
