# FRONTIER — Solo RTS Sandbox

스타크래프트 1의 테란 기지 운영에서 영감을 받아 만든 실험용 브라우저 RTS입니다. 원작 게임 엔진이나 추출 리소스를 사용하지 않으며, 지형·건물·유닛은 Canvas로 직접 제작했습니다. 평지 맵에서 적 AI나 시간 제한 없이 플레이합니다.

## 실행

Node.js가 설치되어 있다면 이 디렉터리에서 `npm start`를 실행하고 <http://127.0.0.1:4173>을 여세요. 추가 패키지 설치나 빌드는 필요 없습니다. 정적 서버에는 `dist` 폴더를 배포하면 됩니다. `dist/index.html`을 직접 열어서도 플레이할 수 있지만, 저장은 로컬 HTTP 서버 사용을 권장합니다.

## 구현 기능

- SCV 선택, 드래그 다중 선택, 우클릭 이동·채집·미완성 건설 재개
- 5개 자원 거점, 소모되는 미네랄 및 베스핀 가스, 기지까지 왕복 운반
- 커맨드 센터·보급고·배럭·정제소·팩토리 건설, 건설 선행 조건 및 배치 충돌 검사
- SCV·마린·시즈 탱크 생산, 최대 5개 생산 대기열, 보급량 예약 및 자원 반환
- 건물·광물 주변 격자 경로 탐색, 그룹 이동 및 간단한 유닛 간 분리
- 집결 지점, 순찰, 정지, 위치 사수, Shift 명령 예약
- 미니맵, 화면 가장자리 및 방향키 스크롤, 휠 확대·축소, 부대 지정
- 일시 정지, 0.5×/1×/2× 속도, 선택적 효과음, 전체 화면
- 15초마다 브라우저 자동 저장, 수동 저장/불러오기 및 확인 후 새 게임
- 한국어 UI, 기지 건설 가이드, 통신 기록, 좁은 화면 대응

## 조작

| 입력 | 기능 |
| --- | --- |
| 좌클릭 / 드래그 | 선택 / 다중 선택 |
| Shift + 좌클릭 | 선택 추가 및 제거 |
| 우클릭 | 이동, 채집, 건설 계속, 건물 집결 지점 |
| Shift + 우클릭 | 명령 예약 |
| 더블클릭 | 화면 안 같은 종류 유닛 선택 |
| Ctrl + 1–9 / 1–9 | 부대 지정 / 부대 선택 |
| 방향키 / 화면 가장자리 | 카메라 이동 |
| 휠 / Space | 확대·축소 / 기지로 이동 |
| B | SCV 건설 메뉴 |
| M / S / H / G | 이동 / 정지 / 위치 사수 / 채집 |
| T | 전투 유닛 순찰 (팩토리 선택 시 탱크 생산) |
| P / Esc | 일시 정지 / 명령 취소 |

명령 버튼 오른쪽 위에도 해당 단축키가 표시됩니다. 적과 전투·멀티플레이·저그·프로토스·기술 연구·공성 모드는 이번 버전에 포함하지 않습니다.

## 검사

`npm run check`는 JavaScript 문법을 확인합니다. `npm test`는 실제 게임 코드의 시뮬레이션을 별도 VM에서 실행하며 채집·배치·건설·선행 조건·가스·생산·보급·취소·경로·건설 재개·저장 복원 등 14개 시나리오를 검증합니다. 테스트의 Canvas/DOM 대역은 게임 로직 검사 목적이며, 실제 화면은 브라우저에서 별도로 확인했습니다.

## 파일

- `dist/index.html`: 게임 UI 및 모달
- `dist/style.css`: 반응형 HUD 스타일
- `dist/game.js`: 시뮬레이션, 자체 그래픽, 입력, 저장
- `server.mjs`: 의존성 없는 로컬 정적 서버
- `test-game.mjs`: 게임 시뮬레이션 검사

StarCraft는 Blizzard Entertainment의 상표입니다. FRONTIER는 공식 제품과 관계없는 개인 실험용 팬 프로젝트입니다.
